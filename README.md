# jinxmesh.com

The web site of [JinxMesh](https://github.com/arugulax/jinxmesh): the landing page (`index.html`), the web
flasher (`flash/`), the firmware it writes (`firmware/`) and the list of maps it offers (`maps/index.json`).

`firmware/` and `maps/index.json` are written by `publish-site.sh` on the `dev` branch. Changes go to
`gh-pages-dev` first; `gh-pages` is what jinxmesh.com serves.
